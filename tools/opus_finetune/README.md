# Донавчання Opus-MT (EN→UK)

Інструменти для донавчання моделі перекладу вузла `Helsinki-NLP/opus-mt-tc-big-en-zle` (CC-BY-4.0) на наших парах
EN→UK: фрази з відео, перекладені й перевірені. Мета — кращий переклад ігрової й розмовної мови без втрати загальної.

- `prep.py`: готує дані й додає пари з плейсхолдерами `N0`/`N1`. Терміни глосарію та латинські імена замінюються на
  плейсхолдери, щоб модель зберігала їх точно один раз, як цього чекає `/translate` вузла.
- `train.py`: донавчання (низький lr 2e-5, рання зупинка за втратою на dev, щоб модель не забула загальну мову).
- `eval.py`: стара й нова модель у CTranslate2 int8, так само як на вузлі. BLEU/chrF на test, на test_random250, на
  загальному наборі Tatoeba (перевірка, що модель не забула загальну мову), частка збережених плейсхолдерів (має бути
  100 %), файли для сліпого судді.
- `run.sh <дані> <робоча тека>`: усе разом на вузлі з відеокартою NVIDIA (docker). `OLD_CT2=<тека en-zle з тому
  translate-cache>` порівнює саме з тією моделлю, що зараз стоїть на вузлах.

Дані: `train.tsv`, `dev.tsv`, `test.tsv`, `test_random250.tsv`, `glossary.tsv` (`en<TAB>uk`), поділені за відео.

Нова модель потрапляє на вузли лише тоді, коли вона помітно краща на наших даних і не гірша на загальному наборі.
Розповсюджується новим тегом образу моделей (`OPUS_MODELS_TAG`) через оновлювач, із позначкою про донавчання в NOTICE.
